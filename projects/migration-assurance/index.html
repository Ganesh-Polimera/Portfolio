PROJECT 02 / WORKING VALIDATION UTILITY

Migration Assurance

A small, repeatable check that turns inventory differences into a review queue.

Run the comparator ↗Read implementation guide ↓

What exists today: a working browser comparison tool and Node.js CLI, synthetic input files, automated tests, and an optional SharePoint Online export script. Microsoft tenant execution has not been performed here.

The problem

A migration can finish while an owner still has missing items. Inventory comparisons help identify where to investigate before sign-off. This project is informed by a 138-source / 105-destination item gap reported in Ganesh’s delivery experience.

How it works

  1. Normalize source and destination inventories to logical site and list keys.
  2. Validate the schema and reject duplicate keys or invalid counts.
  3. Compare both inventories, including destination-only entries.
  4. Export the exception report and investigate each difference.

Sample result

All supplied inventory records are synthetic. Matching counts are a screening result; they do not establish that documents, metadata, versions, pages, or permissions are correct.

Run from the command line

node projects/migration-assurance/cli.mjs +  projects/migration-assurance/source.sample.json +  projects/migration-assurance/destination.sample.json report.json

Exit code 1 means exceptions need review. Code 2 means invalid input or a file error. An empty comparison has no validation coverage.

Implementation decisions

  • Logical keys let renamed destinations map to their original inventories.
  • Missing inventories are distinct from lists with zero items.
  • Case and surrounding whitespace are normalized consistently.
  • Duplicate keys fail fast so records cannot be silently overwritten.
  • Input is rendered as text, and CSV cells are protected against common spreadsheet formula prefixes.

What a release still needs

Investigate every exception, sample content and metadata, test intended and unintended access, validate pages and workflows, then capture owner UAT. The utility makes that review more focused; it does not replace it.
